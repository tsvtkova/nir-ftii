# Алгоритм выставления оценки

## Шаг 1. Проверить обязательные требования

Определить:

- актуальность;
- постановку задачи;
- существующие решения;
- метрики;
- сравнение;
- результат;
- проверку;
- артефакты;
- репозиторий;
- презентацию;
- понимание работы.

## Шаг 2. Оценить критерии

Для каждого критерия выбрать:

**5А / 4В / 4С / 3D / 3E / 2FX**

## Шаг 3. Проверить ограничители

Особое внимание:

- количественному сравнению;
- бейзлайнам;
- воспроизводимости;
- обязательным артефактам;
- пониманию работы студентом;
- специальным требованиям типа проекта.

## Шаг 4. Определить итог

Итоговая оценка — это не среднее арифметическое.

Используется принцип:

> Итоговая оценка отражает наиболее высокий уровень, для которого выполнены все критические требования соответствующего уровня.

### 5А

Полностью завершённый, актуальный, самостоятельный и доказанный результат.

### 4В

Сильный и практически завершённый результат с отдельными существенными недоработками.

### 4С

Хороший содержательный результат с заметными пробелами.

### 3D

Минимально достаточный реально выполненный результат.

### 3E

Погранично достаточный результат с существенной незавершённостью.

### 2FX

Убедительного результата нет либо его качество/самостоятельность невозможно подтвердить.
