# Быстрый чек-лист комиссии

## Можно ли поставить 5А?

Все ответы должны быть «да».

- [ ] Задача действительно актуальна?
- [ ] Актуальность доказана?
- [ ] Есть чёткая постановка и критерии успеха?
- [ ] Проанализированы существующие решения?
- [ ] Есть релевантный бейзлайн/аналог?
- [ ] Есть количественные метрики?
- [ ] Есть количественное сравнение с аналогами?
- [ ] Сравнение проведено в сопоставимых условиях?
- [ ] Результат превосходит или дополняет аналоги, и это доказано?
- [ ] Для сложной системы проведён анализ компонентов?
- [ ] Все обязательные артефакты представлены?
- [ ] Репозиторий качественный и воспроизводимый?
- [ ] Код соответствует заявленному результату?
- [ ] Презентация качественно показывает результат?
- [ ] Студент понимает собственную работу?
- [ ] Студент способен ответить на вопросы комиссии?
- [ ] Выполнены специальные требования типа проекта?

**Если хотя бы один ответ «нет», 5А не выставляется.**

## Ограничители

| Ситуация | Максимальная оценка |
|---|---|
| Нет всех обязательных артефактов | 4В |
| Нет количественного сравнения с аналогами | 4С |
| Нет содержательного бейзлайна/аналога | 3D |
| Нет анализа компонентов в сложной системе | 4С |
| Студент не объясняет существенную часть работы | 3D |
| Не доказана актуальность | 4С |
| Нет работающего/проверяемого результата | 3E, при отсутствии содержательного результата — 2FX |
| Репозиторий не позволяет проверить результат | 4С |
| Нет обязательной индустриальной рецензии | 4В |
| Групповой проект существенно меньше требуемого масштаба | 4С |
| Нельзя определить индивидуальный вклад | 4С |
| Презентация не позволяет понять задачу, метод и результаты | 4С |
| Студент не отвечает на базовые вопросы | 3D |
