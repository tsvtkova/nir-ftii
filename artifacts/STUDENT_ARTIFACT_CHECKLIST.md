# Чек-лист артефактов студента

## Перед защитой

- [ ] Выбран тип проекта.
- [ ] Загружены все обязательные артефакты.
- [ ] Ссылки на артефакты внесены в таблицу записи на защиту.
- [ ] Репозиторий доступен комиссии.
- [ ] README содержит инструкцию по запуску.
- [ ] Основные результаты можно воспроизвести.
- [ ] Присутствует количественное сравнение с аналогами.
- [ ] Используются релевантные метрики.
- [ ] Презентация содержит постановку, метод, эксперименты и результаты.
- [ ] Студент может объяснить собственную работу.

## Специально для типов

### Научный
- [ ] Репозиторий
- [ ] Препринт
- [ ] Презентация

### Технологический
- [ ] Репозиторий
- [ ] Техническое описание/отчёт
- [ ] Презентация

### Индустриальный
- [ ] Рецензия индустриального представителя
- [ ] Описание проекта
- [ ] Презентация

### Коллаборативный
- [ ] Оценка команды
- [ ] Описание проекта
- [ ] Презентация

### Групповой
- [ ] Общий результат
- [ ] Описаны зоны ответственности
- [ ] Подтверждён индивидуальный вклад
- [ ] Масштаб соответствует числу участников
