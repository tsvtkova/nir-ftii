## Общие принципы оценивания

5А - отлично / проект высокого уровня, все требования выполнены в полном объёме

4В - хорошо / высокий уровень, но требования выполнены не в полном объёме

4С - хорошо / достаточный высокий уровень

3D - удовлетворительно / минимально достаточный уровень

3E - удовлетворительно / погранично достаточный уровень

2FX - неудовлетворительно / результат требует существенной доработки

## Оценка определяется не только количеством выполненной работы, но и совокупностью следующих характеристик:

актуальность и обоснованность постановки задачи;  
степень проработки задачи;  
качество и самостоятельность полученного результата;  
качество экспериментальной или практической проверки;  
наличие и качество сравнения с существующими решениями и аналогами;  
качество кода и репозитория;  
качество основного текстового артефакта;  
качество презентации и доклада;  
способность студента объяснить принятые решения и полученные результаты;  
соответствие результата заявленному типу проекта;  
для группового и коллаборативного проектов — качество командной работы и индивидуальный вклад.  

## Обязательные условия для оценки 5А

# Оценка 5А не может быть выставлена, если отсутствует хотя бы одно из следующих принципиальных условий.

## 1. Представлены все обязательные артефакты

Проект должен содержать все артефакты, предусмотренные для соответствующего типа проекта:

- [ ] репозиторий с кодом — если он предусмотрен типом проекта;  
- [ ] научный препринт / технологический отчёт / описание решения;  
- [ ] презентацию по необходимому шаблону, включающую все обязательные разделы;  
- [ ] рецензию индустриального партнёра — для индустриального проекта;  
- [ ] оценку командного вклада — для коллаборативного проекта;  
- [ ] индивидуальный отчёт о вкладе — для группового проекта.  

Отсутствие обязательного артефакта автоматически ограничивает максимальную оценку ниже 5А.

Наличие ссылки само по себе не считается наличием качественного артефакта: артефакт должен содержательно соответствовать требованиям проекта.

## 2. Проведено сравнение с существующими решениями

Для получения 5А необходимо показать, чем предложенное решение отличается от существующих подходов и насколько оно эффективно относительно них.

Сравнение должно включать:

- [ ] релевантные существующие методы, алгоритмы, модели, системы или инструменты;  
- [ ] чётко определённые метрики;  
- [ ] одинаковые или сопоставимые условия эксперимента;  
- [ ] количественные результаты;  
- [ ] интерпретацию полученных различий.  

Формулировка «наш метод лучше» без количественного подтверждения не является сравнением.

Примеры допустимого сравнения:

- [ ] качество: Accuracy, F1, ROC-AUC, BLEU, ROUGE, pass@k и т. п.;  
- [ ] скорость: latency, throughput;  
- [ ] вычислительная эффективность: время обучения, GPU hours, memory;  
- [ ] стоимость: количество токенов, стоимость API-вызовов, стоимость инференса;  
- [ ] надёжность: failure rate, success rate;  
- [ ] качество генерации: task success rate, human evaluation;  
- [ ] для индустриальных задач — бизнес-метрики, экономический эффект, сокращение времени или ресурсов.  

Если сравнение с аналогами отсутствует, оценка 5А невозможна.

## 3. Результат воспроизводим

Другой исследователь или разработчик должен иметь возможность понять:

- [ ] какие данные использовались;  
- [ ] как подготовлены данные;  
- [ ] какая модель/алгоритм использовались;  
- [ ] какие параметры выбраны;  
- [ ] как запустить код;  
- [ ] как получить основные результаты;  
- [ ] какие ограничения есть у эксперимента.  

## 4. Студент понимает собственную работу

На защите студент должен самостоятельно и уверенно объяснить:

- [ ] постановку задачи;  
- [ ] используемый метод;  
- [ ] архитектуру решения;  
- [ ] ключевые алгоритмы;  
- [ ] экспериментальный дизайн;  
- [ ] метрики;  
- [ ] бейзлайн;  
- [ ] результаты;  
- [ ] ограничения;  
- [ ] причины полученных результатов.  

Наличие работающего кода не компенсирует отсутствие понимания собственного решения.

Если студент не может объяснить существенную часть своей работы, это является основанием для снижения оценки независимо от наличия артефактов.
