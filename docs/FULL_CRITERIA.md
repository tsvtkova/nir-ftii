# Расширенные критерии оценивания НИР магистров

## Общие принципы

Оценивание проводится по шести уровням:

- 5А — отлично;
- 4В — хорошо, высокий уровень;
- 4С — хорошо, достаточный высокий уровень;
- 3D — удовлетворительно, минимально достаточный уровень;
- 3E — удовлетворительно, погранично достаточный уровень;
- 2FX — неудовлетворительно.

Оцениваются:

1. актуальность и обоснованность постановки;
2. степень проработки;
3. качество и самостоятельность результата;
4. экспериментальная/практическая проверка;
5. сравнение с решениями и аналогами;
6. код и репозиторий;
7. основной текстовый артефакт;
8. презентация и доклад;
9. понимание студентом собственных решений;
10. соответствие типу проекта;
11. командная работа и индивидуальный вклад там, где это применимо.

## Обязательные условия 5А

### Все обязательные артефакты

Отсутствие обязательного артефакта автоматически ограничивает максимальную оценку ниже 5А.

### Количественное сравнение

Для 5А необходимо показать, чем решение отличается от существующих подходов и насколько оно эффективно относительно них.

Сравнение должно включать:

- релевантные методы/модели/системы;
- чёткие метрики;
- сопоставимые условия;
- количественные результаты;
- интерпретацию различий.

### Воспроизводимость

Другой исследователь или разработчик должен понять:

- какие данные использовались;
- как они подготовлены;
- какой метод применён;
- какие параметры выбраны;
- как запустить код;
- как получить основные результаты;
- какие ограничения есть.

### Понимание собственной работы

Студент должен объяснить:

- постановку;
- метод;
- архитектуру;
- ключевые алгоритмы;
- экспериментальный дизайн;
- метрики;
- бейзлайн;
- результаты;
- ограничения;
- причины полученных результатов.

Работающий код не компенсирует отсутствие понимания.

## Ограничения максимальной оценки

| Ситуация | Максимум |
|---|---|
| Не представлены все обязательные артефакты | 4В |
| Нет количественного сравнения с аналогами | 4С |
| Нет содержательного бейзлайна/аналога | 3D |
| Нет анализа компонентов сложной системы | 4С |
| Студент не объясняет существенную часть работы | 3D |
| Не доказана актуальность | 4С |
| Нет работающего результата | 3E / 2FX |
| Репозиторий не позволяет проверить результат | 4С |
| Нет индустриальной рецензии | 4В |
| Групповой масштаб недостаточен | 4С |
| Индивидуальный вклад невозможно определить | 4С |
| Презентация не позволяет понять работу | 4С |
| Нет ответов на базовые вопросы | 3D |

## Принцип «недостаточно просто сделать»

Недостаточно:

- реализовать модель;
- получить одну метрику;
- показать красивый график;
- сравнить две версии собственного метода;
- заявить «наша модель лучше» без объяснения бейзлайна;
- заявить, что решение новое;
- заявить, что оно применимо в индустрии;
- показать прототип без анализа аналогов.

Необходимо показать:

**задача → актуальность → существующие решения → gap → собственный вклад → метод → эксперимент → метрики → сравнение → анализ → вывод.**

Для сложных систем:

**система → компоненты → вклад компонентов → ablation study → сравнение → итоговый эффект.**

## Итоговая интерпретация

### 5А
Полностью завершённый, актуальный, самостоятельный и убедительно доказанный результат.

### 4В
Сильный и практически завершённый результат с отдельными существенными недоработками.

### 4С
Хороший содержательный результат с заметными пробелами.

### 3D
Минимально достаточный результат: работа действительно выполнена, но значительная часть требований недоработана.

### 3E
Погранично достаточный результат: признаки самостоятельной работы есть, но проект существенно не завершён.

### 2FX
Убедительного результата нет либо невозможно подтвердить его качество, воспроизводимость или самостоятельность.
