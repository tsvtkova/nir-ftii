# Обязательные артефакты

## Научный проект

1. Открытый репозиторий с кодом реализации научной задачи и проведения экспериментов. Репозиторий должен включать корректно оформленный README.
2. Препринт научной статьи в шаблоне журнала или конференции, куда планируется подача в течение 3 месяцев после завершения проекта.
3. Презентация с постановкой задачи, ходом решения и основными результатами.

## Технологический проект

1. Открытый репозиторий с кодом и README.
2. Описание технологического решения: технологическая статья или полный технический отчёт.
3. Презентация.

## Индустриальный проект

1. Рецензия представителя индустрии с оценкой уровня решения и потенциала использования результатов.
2. Описание промышленного проекта: технологическая статья, технический отчёт или научно-популярная статья.
3. Презентация.

Рецензия направляется самим рецензентом на указанную организаторами почту/в Telegram.

## Коллаборативный проект

1. Оценка от команды: способность решать задачи в сроки и soft skills. Ревью заполняет тимлид проекта или руководитель НИР.
2. Описание проекта: технологическая статья, технический отчёт, научно-популярная статья или документация к репозиторию.
3. Презентация.

## Групповой проект

Для группового проекта необходимо дополнительно фиксировать индивидуальный вклад каждого участника и подтверждать соответствие масштаба проекта числу участников.

## Важно

Наличие ссылки не означает наличие качественного артефакта.

Например:

- несколько строк README не являются полноценной документацией;
- таблица с числами не является корректным экспериментальным сравнением;
- утверждение «наш метод лучше» без сопоставимых условий и метрик не является сравнением.
