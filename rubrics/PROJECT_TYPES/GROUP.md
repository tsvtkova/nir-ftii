# Групповой проект

Для группы из N человек проект должен быть сопоставим по масштабу и сложности с N индивидуальными проектами.

## 5А
Комплексный результат соответствует масштабу группы; у каждого участника есть самостоятельная содержательно значимая зона; компоненты интегрированы; есть количественное сравнение; результат воспроизводим; все артефакты представлены; индивидуальные вклады подтверждены; каждый участник способен объяснить свою часть.

Нельзя получить 5А за одну небольшую индивидуальную работу, искусственно разделённую между несколькими студентами.

## 4В
Полноценный комплексный проект, масштаб в целом соответствует группе, компоненты интегрированы, есть измеримые результаты и сравнение.

## 4С
Достаточный групповой масштаб и работающий общий результат, но отдельные части или вклады существенно менее проработаны.

## 3D
Несколько частей существуют, но масштаб или качество недостаточны.

## 3E
Формально групповой проект, фактически не соответствующий требуемому масштабу.

## 2FX
Нет единого результата, масштаб существенно недостаточен или индивидуальные вклады невозможно определить.
