# Система оценивания НИР магистров

Репозиторий содержит методические материалы для оценивания НИР магистров.

## Структура

- `README.md` — краткая инструкция для быстрого использования.
- `docs/` — подробная документация и критерии оценивания.
- `rubrics/` — оценочные матрицы по типам проектов.
- `artifacts/` — требования к обязательным артефактам и шаблоны чек-листов.
- `commission/` — материалы для членов комиссии.
- `templates/` — заготовки для индивидуальной работы студентов.
- `scripts/` — вспомогательные скрипты для автоматической проверки структуры репозитория.

## Два уровня документации

### Уровень 1 — быстрое использование

Если нужно быстро разобраться перед защитой, откройте:

1. `commission/QUICK_CHECKLIST.md`
2. `commission/SCORING_FLOW.md`
3. `rubrics/GENERAL_MATRIX.md`
4. соответствующий файл в `rubrics/PROJECT_TYPES/`

### Уровень 2 — полная методика

Полные критерии находятся в:

- `docs/FULL_CRITERIA.md`
- `docs/ARTIFACT_REQUIREMENTS.md`
- `rubrics/GENERAL_MATRIX.md`
- `rubrics/PROJECT_TYPES/`

## Типы проектов

В системе используются четыре типа проектов:

- научный;
- технологический;
- индустриальный;
- коллаборативный.

## Оценки

- 5А — отлично;
- 4В — хорошо, высокий уровень;
- 4С — хорошо, достаточный высокий уровень;
- 3D — удовлетворительно, минимально достаточный уровень;
- 3E — удовлетворительно, погранично достаточный уровень;
- 2FX — неудовлетворительно.

## Главный принцип

Итоговая оценка определяется не простым средним арифметическим, а уровнем, для которого выполнены критические требования.

Особенно важно:

- без всех обязательных артефактов нельзя поставить 5А;
- без количественного сравнения с существующими решениями нельзя поставить 5А;
- без содержательного бейзлайна/аналога максимальная оценка — 3D;
- студент должен понимать и уметь защитить собственную работу;
- для сложных систем требуется анализ вклада компонентов;
- для индустриального проекта обязательна оценка индустриального партнёра;
- для коллаборативного проекта оценивается индивидуальный вклад.
